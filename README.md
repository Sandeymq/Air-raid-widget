Як використовувати:
1. Завантажте Übersicht
2. Завантажте віджет з релізів або за допомогою команди git clone https://github.com/dr-mod/air-raid-widget-macos.git
3. Два кліки по Übersicht, далі нажміть на іконку Übersicht в статус барі.
4. Виберіть Open widgets folder та скопіюйте папку віджета сюди. Віджет має запуститись
